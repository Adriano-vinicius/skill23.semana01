# Projeto: Baseline de Bancada e Inventário Competitivo - Semana 01
**WorldSkills Skill 23 - Autonomous Mobile Robotics**

Este repositório contém a linha de base competitiva para o treinamento da Skill 23. O objetivo desta semana é estabelecer controle operacional, segurança, rastreabilidade e comunicação técnica desde o primeiro dia de trabalho através do inventário, organização da bancada e documentação rigorosa.

## 🛠️ Estrutura do Repositório

O repositório está organizado seguindo a arquitetura padrão exigida:

* `/docs` - Documentos de texto, inventário detalhado e diários técnicos.
* `/evidencias/fotos` - Fotos numeradas e identificadas dos componentes do kit.
* `/evidencias/videos` - Vídeo curto de validação (60-90 segundos).
* `/logs` - Logs de sistema e registros de erros.
* `/issues` - Rastreador de problemas para componentes danificados ou ausentes.
